# Glossary

The names specs and case columns use, with their units and meanings, in
game terms. Never the original's identifiers. Add terms as specs need
them; clean mode answers only in these names.

## Time

- **field**: one display field (vblank), the unit of a case's rows.
- **tick**: one update of the game's logic. `fields_per_tick` in a case
  says how many fields a tick takes in steady play.
